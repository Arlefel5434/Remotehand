# План MVP Remotehand

## Цель

С телефона в одной локальной сети управлять личным Windows-ноутбуком:

- перемещать курсор;
- выполнять левый и правый клик;
- вводить Unicode-текст;
- менять системную громкость и включать mute.

Телефон использует веб-интерфейс/PWA. Разработка, тесты, mock-сервер и сборка
выполняются через Docker Compose. Собранный Go-agent запускается нативно в
Windows, принимает команды по WebSocket и вызывает Windows API.

## Граница Docker

Docker является единой точкой входа для разработки: локальный Go не требуется.
Однако Windows-agent нельзя исполнять внутри Linux-контейнера: контейнер не
имеет доступа к интерактивной Windows-сессии, `SendInput` и Core Audio хоста.
Поэтому Docker собирает `.exe`, а Windows запускает этот артефакт нативно.

## Ключевые предположения

- телефон и ноутбук находятся в одной доверенной Wi-Fi-сети;
- браузерного интерфейса достаточно для первой версии;
- задержка WebSocket позволяет комфортно двигать курсор;
- Windows разрешает синтетический ввод в обычные пользовательские окна;
- управление защищёнными окнами UAC не требуется.
- Docker Desktop интегрирован с используемым WSL-дистрибутивом.

## Не входит в MVP

- Android/iOS-приложение;
- Bluetooth, USB и доступ через интернет;
- передача файлов и синхронизация буфера обмена;
- сложные мультитач-жесты и все сочетания клавиш;
- автозапуск Windows, установщик и автоматическое обновление;
- Linux/macOS и несколько одновременных клиентов.
- запуск Windows-agent внутри контейнера.
