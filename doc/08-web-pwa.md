# Этап 8. Веб-интерфейс и PWA

## Результат этапа

Все функции MVP удобно доступны на экране телефона, а интерфейс можно добавить
на домашний экран.

## Шаги

1. Создать большую область тачпада с Pointer Events.
2. Добавить кнопки левого и правого клика.
3. Добавить поле текста и кнопки Enter, Backspace, Escape.
4. Добавить громкость, mute и отображение текущего уровня.
5. Отображать состояния connecting, connected и disconnected.
6. Отключить браузерную прокрутку и выделение внутри тачпада.
7. Добавить manifest, иконки и минимальный service worker.
8. Встроить статические файлы в бинарник через `go:embed`.
9. Проверить портретную и альбомную ориентацию.

## Проверка

1. Все элементы доступны без масштабирования страницы.
2. Жест по тачпаду не прокручивает браузер.
3. Интерфейс корректно сообщает о потере соединения.
4. Страницу можно добавить на домашний экран.
5. Один `.exe` работает без внешнего каталога `web`.

## Критерий готовности

Полный сценарий управления выполняется с телефона одним пальцем, интерфейс не
мешает системными жестами браузера.
