# Этап 7. Управление громкостью

## Результат этапа

Телефон меняет общую системную громкость Windows и состояние mute.

## Шаги

1. Определить интерфейс `VolumeController`.
2. Реализовать адаптер Windows Core Audio через COM.
3. Поддержать получение и установку уровня `0..100`.
4. Добавить относительные команды увеличения и уменьшения.
5. Добавить mute/unmute.
6. Возвращать клиенту фактическое состояние после каждой операции.
7. Корректно освобождать COM-ресурсы и обрабатывать смену аудиоустройства.

## Проверка

1. Кнопки `+` и `-` меняют системную громкость.
2. Значение не выходит за `0..100`.
3. Mute включается и выключается.
4. Клиент показывает фактическое, а не предполагаемое значение.
5. После смены устройства вывода приложение не падает.

## Критерий готовности

С телефона можно установить минимальную, среднюю и максимальную громкость и
переключить mute; состояние интерфейса совпадает с Windows.

## Коммит

`feat: control Windows system volume`
