# Этап 5. Ввод текста

## Результат этапа

Телефон отправляет Unicode-текст и несколько необходимых управляющих клавиш в
активное окно Windows.

## Шаги

1. Определить интерфейс `KeyboardController`.
2. Реализовать Unicode-ввод через Windows `SendInput`.
3. Отправлять готовый фрагмент текста, а не каждое событие экранной клавиатуры.
4. Добавить отдельные команды Enter, Backspace и Escape.
5. Ограничить длину текста и валидировать UTF-8.
6. Исключить содержимое текста из логов.
7. Написать тесты валидации и преобразования команд.

## Проверка

В Windows Notepad последовательно проверить:

- `Remotehand 123`;
- `Привет, мир!`;
- перенос строки через Enter;
- удаление символа через Backspace;
- длинную строку в пределах установленного лимита.

## Критерий готовности

Латиница, кириллица, цифры и основные знаки вводятся без искажений; неверный
UTF-8 и слишком длинные сообщения отклоняются.
