## Результат этапа

Воспроизводимый `remotehand.exe` прошёл полный сценарий, документация актуальна,
версия `v0.1.0` опубликована в Git.

## Шаги

1. Добавить версию сборки и команду создания `dist/remotehand.exe`.
2. Запустить форматирование, статический анализ, тесты и Windows-сборку.
3. Проверить приложение на чистом запуске Windows.
4. Обновить README: запуск, Firewall, подключение, ограничения и остановка.
5. Выполнить ручной приёмочный сценарий ниже.
6. Зафиксировать изменения, создать annotated tag `v0.1.0`.
7. Отправить ветку `main` и тег в `origin`.

## Автоматическая проверка

```bash
gofmt -w .
go vet ./...
go test ./...
GOOS=windows GOARCH=amd64 go build -o dist/remotehand.exe ./cmd/remotehand
git status --short
```

## Ручная приёмка

1. Запустить `remotehand.exe` в Windows.
2. Подключить телефон по выданному адресу и токену.
3. Переместить курсор и выполнить левый/правый клик.
4. Ввести английский и русский текст в Notepad.
5. Изменить громкость и переключить mute.
6. Отключить Wi-Fi телефона, затем восстановить соединение.
7. Проверить отказ клиента без токена.
8. Перезапустить `.exe` и убедиться, что старый токен недействителен.

## Критерий готовности
