# Этап 3. HTTP-сервер и доступ из телефона

## Результат этапа

Телефон открывает страницу, которую Go-приложение раздаёт по локальной сети.

## Шаги

1. Реализовать HTTP-сервер с конфигурируемым адресом, по умолчанию `:18080`.
2. Добавить `GET /health`, возвращающий `200 OK` и `ok`.
3. Добавить минимальную страницу на `GET /`.
4. Добавить таймауты HTTP-сервера и корректное завершение по сигналу.
5. Печатать адрес подключения и понятные ошибки запуска.
6. Сначала запустить mock-сервер через Docker Compose и проверить HTTP.
7. Затем запустить Windows-сборку и разрешить доступ только в частной сети Firewall.

## Проверка

1. Выполнить `docker compose up --build server`.
2. На ноутбуке открыть `http://localhost:18080/health`.
3. Узнать локальный IPv4-адрес Windows через `ipconfig`.
4. На телефоне в той же Wi-Fi-сети открыть `http://<ip>:18080/`.
5. Выполнить `docker compose down` и проверить остановку страницы.
6. Повторить проверку с нативным `dist/remotehand.exe`.

## Критерий готовности

Страница стабильно открывается с телефона, сервер корректно запускается и
останавливается. Пока это не работает, WebSocket не добавлять.
