# Этап 2. HTTP-сервер и доступ из телефона

## Результат этапа

Телефон открывает страницу, которую Go-приложение раздаёт по локальной сети.

## Шаги

1. Реализовать HTTP-сервер с конфигурируемым адресом, по умолчанию `:8080`.
2. Добавить `GET /health`, возвращающий `200 OK` и `ok`.
3. Добавить минимальную страницу на `GET /`.
4. Добавить таймауты HTTP-сервера и корректное завершение по сигналу.
5. Печатать адрес подключения и понятные ошибки запуска.
6. Запустить Windows-сборку и разрешить доступ только в частной сети Firewall.

## Проверка

1. На ноутбуке открыть `http://localhost:8080/health`.
2. Узнать локальный IPv4-адрес Windows через `ipconfig`.
3. На телефоне в той же Wi-Fi-сети открыть `http://<ip>:8080/`.
4. Остановить сервер и убедиться, что страница больше не открывается.
5. Повторить запуск и убедиться, что порт освобождён корректно.

## Критерий готовности

Страница стабильно открывается с телефона, сервер корректно запускается и
останавливается. Пока это не работает, WebSocket не добавлять.
