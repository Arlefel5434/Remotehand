## Автоматическая проверка

```bash
docker compose config

docker compose run --rm build-windows
test -f dist/remotehand.exe
git status --short
```

## Ручная приёмка

Для проверки кандидата выполните `make build-windows`. Значение по умолчанию
`v0.1.0-rc.1` отображается в журнале запуска и в `/health`. В каталоге
`dist` появляются исполняемый файл, ZIP и SHA256SUMS. Проверьте их командой
`(cd dist && sha256sum -c SHA256SUMS)`. После ручной приёмки для финальной
сборки используйте `REMOTEHAND_VERSION=v0.1.0 make build-windows`.

1. Запустить `remotehand.exe` в Windows.
2. Подключить телефон по выданному адресу и токену.
3. Переместить курсор и выполнить левый/правый клик.
4. Ввести английский и русский текст в Notepad.
5. Изменить громкость и переключить mute.
6. Отключить Wi-Fi телефона, затем восстановить соединение.
7. Проверить отказ клиента без токена.
8. Перезапустить `.exe` и убедиться, что старый токен недействителен.
9. На iPhone проверить поворот экрана, системную клавиатуру, жест двумя
   пальцами и повторное сопряжение после смены Wi-Fi на точку доступа.
10. При потере связи до подтверждения ввода проверить сохранение черновика
    и отсутствие повторного ввода при восстановлении соединения.
11. После ошибки аудиоустройства подключить устройство воспроизведения
    и проверить восстановление ползунка в том же сеансе.
